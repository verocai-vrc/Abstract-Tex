\section*{Listings}

The orchestrator's cancel-and-restart loop, in Rust:

\begin{minted}[linenos, frame=lines]{rust}
pub async fn build(&self, job: &BuildJob, cancel: CancellationToken) -> Result<BuildOutcome, EngineError> {
    let mut child = self.command(job).spawn()?;
    tokio::select! {
        status = child.wait() => self.outcome(job, status?),
        _ = cancel.cancelled() => {
            child.kill().await?;
            Err(EngineError::Cancelled)
        }
    }
}
\end{minted}

The same idea, in Python:

\begin{minted}[linenos, frame=lines]{python}
async def build(job, cancel):
    child = await asyncio.create_subprocess_exec(*command(job))
    done, _ = await asyncio.wait({child.wait(), cancel.wait()}, return_when=FIRST_COMPLETED)
    if cancel.is_set():
        child.kill()
        raise Cancelled()
    return outcome(job, child.returncode)
\end{minted}
